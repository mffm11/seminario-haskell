# Seminário de Haskell — Imutabilidade em uma Lista de Tarefas

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte de um seminário acadêmico sobre a linguagem de programação Haskell, abordando o conceito de **imutabilidade em uma lista de tarefas (To-Do List)**.

O objetivo é demonstrar como a imutabilidade funciona na programação funcional, utilizando funções puras, tuplas e pattern matching para manipular uma lista de tarefas sem modificar os dados originais.

## 🎯 Objetivos

* Compreender o conceito de imutabilidade.
* Explorar o funcionamento de funções puras.
* Utilizar tuplas na representação de dados.
* Aplicar pattern matching.
* Desenvolver funcionalidades para manipulação de uma lista de tarefas em Haskell.

## 🛠️ Tecnologias Utilizadas

* Haskell
* GHC (Glasgow Haskell Compiler)
* GHCi
* Visual Studio Code

## ▶️ Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/mffm11/seminario-haskell.git
```

2. Entre na pasta do projeto:

```bash
cd seminario-haskell
```

3. Execute o arquivo Haskell:

```bash
runghc Main.hs
```
